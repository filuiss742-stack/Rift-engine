# World soundtracks

The game has four world identities: Thea's distortion, Earth/Lisa, ruined fantasy/Mira, and the fourth-world Warfront campaign.

| World / viewpoint | Score ID | Scene use | Musical direction |
|---|---|---|---|
| Thea's distortion | `thea` | Opening rift sequence | Dark low drones, unstable pulses, dissonant upper tones |
| Earth / Lisa | `earth` | Apartment and modern street | Warm keys, gentle pulse, light melodic phrases |
| Ruined fantasy / Mira | `mira` | Awakening and first exploration | Airy strings, sparse distant percussion |
| Fourth world / Warfront | `warfront` | Magitech RTS campaign and large-scale battles | High-energy orchestral-industrial warfare theme, driving strings, brass calls, heavy war drums and escalating battle rhythm |

## Officially approved Warfront theme

The user has officially approved **Warfront — Full Battle** (code-composed prototype, 126 BPM, 4/4, 48 bars / approximately 91.4 seconds) as the soundtrack identity for world four.

The approved arrangement consists of four synchronized stems:
- `01_foundation`: harmonic foundation, bass and pulsing cellos.
- `02_brass_theme`: main heroic brass melody.
- `03_war_drums`: combat percussion.
- `04_battle_drive`: additional counter-rhythm and battle intensity.

The full battle mix is `Warfront_FullBattle`; the lighter strategic preview is `Warfront_Strategy_Preview`. The approved prototype package and rendered audio are retained as conversation artifacts for now. The binary masters still need to be imported into the repository's runtime asset directory before the game can load them. Do not claim the soundtrack is integrated or playable in-game yet.

Composer source: `tools/audio/warfront_composer.c`. It renders using C and the FluidSynth shared library with a General MIDI SoundFont. The renderer currently expects the SoundFont at `/usr/share/sounds/sf2/TimGM6mb.sf2`; make this path configurable before using it in portable CI or developer tooling.

## Runtime status and next steps

The current game audio API can load and loop music, but it does not yet provide a full adaptive music mixer. The Warfront stems share tempo, duration and start position, making them suitable for synchronized playback once a mixer/bus implementation exists.

Before runtime integration:
1. Import the approved master and four stems into `assets/audio/worlds/warfront/` (or the final shared asset root).
2. Add asset metadata documenting sample rate, duration, BPM, bar count and loop boundaries.
3. Implement synchronized stem playback with bar-aligned layer changes and short gain ramps; never restart the foundation when combat intensity changes.
4. Verify Android and desktop decoding, loop continuity, clipping/headroom, and real-device playback.
5. Keep the approved master unchanged; revisions must be separate versioned takes and require user approval.

The existing prologue scores are generated by `engine.audio.ProceduralMusicAsset`. Their current world-transition playback is separate from the approved Warfront master and future adaptive RTS mixer.
